# ข้อมูลจำลองสำหรับทดสอบเวอร์ชัน Dashboard

ชุดข้อมูลนี้เป็นข้อมูลจำลองสำหรับทดลองอัปโหลดผ่านหน้า Admin เท่านั้น ไม่ใช่ข้อมูลทางการ

## เวอร์ชันแนะนำสำหรับการทดลอง

- รหัสเวอร์ชัน: `demo-2025-v1`
- ชื่อที่ผู้ใช้เห็น: `ข้อมูลจำลองปี 2025`
- รายละเอียด: `ชุดทดลองระบบเลือกเวอร์ชัน Dashboard`

## วิธีอัปโหลด

1. เปิดหน้า Admin แล้วเลือกแท็บ **อัปเดต Dashboard**
2. เลือก **สร้างเวอร์ชันใหม่** และกรอกข้อมูลเวอร์ชันด้านบน
3. เลือกประเภท **ผลผลิตข้าวรายปี** แล้วเลือกไฟล์ `province_yearly_yield_demo.csv`
4. หลังอัปโหลดครั้งแรก ให้เลือกเวอร์ชัน `ข้อมูลจำลองปี 2025` ที่สร้างไว้
5. เลือกประเภท **สภาพแวดล้อมรายเดือน** แล้วเลือกไฟล์ `province_monthly_environment_demo.csv`
6. เลือกประเภท **ผลพยากรณ์ผลผลิต** แล้วเลือกไฟล์ `province_yearly_predictions_demo.csv`

ไม่ควรกำหนดชุดข้อมูลจำลองเป็นเวอร์ชันเริ่มต้น หากยังต้องการให้ผู้ใช้ทั่วไปเห็นข้อมูลจริงเป็นค่าเริ่มต้น
